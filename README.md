## Фоновое видео
Видео работает с `autoplay muted loop playsinline`, затемняется CSS и масштабируется для десктопа/мобильного экрана. В `assets/hero-video.js` используется стандартный бесшумный автозапуск iOS/Android и остановка при скрытой вкладке. При запрете автозапуска самим браузером остаётся постер; принудительно обходить ограничения iOS сайт не может. Подложка содержит текст «Work time.», который встроен в исходное видео; на десктопе позиция кадра выбрана так, чтобы он не перекрывал заголовок.



## Видео на главной: V4 — корректная встроенная подложка iPhone
- Упрощена реализация до **одного** `<video autoplay muted loop playsinline>`; удалена дополнительная фоновая копия видео.
- Исправлен слой видео: `z-index: 0`, а текст поверх него. Ранее отрицательный `z-index` мог приводить к проблемам аппаратной композиции WebKit.
- Удалены все вызовы `pause()` из управляющего скрипта, сняты проверки видимости элемента и дополнительные политики экономии данных. Нативный autoplay — главный механизм.
- Без кнопки: если iOS отклоняет начальный autoplay, код мягко повторяет попытку на `pageshow`, `loadeddata`, после возвращения на вкладку и при обычном первом касании пользователя.
- Исходный опубликованный файл `studio-worktime.mp4` проверен: Git blob 5cfd957663cc18ab4acf86f8a6dec2e3fd20492a, H.264 High L3.1, `yuv420p`, 24fps, без аудиодорожки, MP4 faststart с `moov` в начале.
- В Chromium c мобильной эмуляцией и десктопным viewport именно этот MP4 воспроизводится и `currentTime` растёт. Safari на реальном iPhone ещё необходимо проверить.
- Оригинальный вертикальный кадр без обрезки (`contain`), размытие фона по постеру за ним, затемнение под текстом.
