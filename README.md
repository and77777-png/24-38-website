## Проверка карты
Вместо Leaflet (разлетавшаяся плиточная карта при недоступности внешней CSS) применено iframe OpenStreetMap внутри контейнера фиксированной высоты с переключателем филиалов. Номера и маршруты 2ГИС доступны независимо от загрузки карты. Положение строения на Высотной ориентировочное.

Локально проверена геометрия аналогичной карты в Chromium на ширинах 320, 360, 375, 390, 430, 600, 760, 768, 900, 1024, 1280 и 1440 px: горизонтального переполнения нет. Внешнюю загрузку тайлов внутри встроенной карты проверить из офлайн-среды нельзя.

## Фоновое видео
Видео работает с `autoplay muted loop playsinline`, затемняется CSS и масштабируется для десктопа/мобильного экрана. В `assets/hero-video.js` реализованы остановка при скрытой вкладке, недоступной видимости, настройке `prefers-reduced-motion` и режиме экономии данных. При блокировке автозапуска остаётся постер. Подложка содержит текст «Work time.», который встроен в исходное видео; на десктопе позиция кадра выбрана так, чтобы он не перекрывал заголовок.

## Исправление фонового видео V2
- Яркость видео увеличена; тёмный градиент сохранён преимущественно под текстом, чтобы видео было видно на десктопе.
- На телефоне видео показывается без тяжёлого CSS-фильтра. `muted autoplay loop playsinline webkit-playsinline` и `preload=auto` облегчают запуск в мобильном Safari.
- При блокировке автозапуска браузером появляется кнопка «Включить видео», которая запускает воспроизведение по пользовательскому нажатию. Если автозапуск недоступен, постер остаётся читаемой подложкой.
- При `prefers-reduced-motion` видео не запускается автоматически, но посетитель может включить его вручную.
- На некоторых iPhone в режиме энергосбережения автозапуск невозможен независимо от кода страницы — для этого предусмотрена кнопка.
