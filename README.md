# 24/38 — профессиональная студия детейлинга и магазин плёнок

Адрес сайта: https://and77777-png.github.io/24-38-website/

## Дизайн V5

Полный пересмотр внешнего оформления без использования прежних V1–V4 CSS слоёв. Единая стилистика: угольно-чёрный фон, насыщенный жёлтый акцент, спортивная типографика и адаптивные секции. Главный экран использует **локальный** файл `assets/hero-corvette.webp` — оригинальное изображение жёлтого спорткара, созданное для этого проекта; никаких внешних хотлинков или старой контурной машины в композиции нет. Изображение не является примером реально выполненной работы 24/38.

## Разделы

`index.html` — главная; `services.html` — 13 направлений; `shop.html` — 12 демонстрационных категорий плёнок, поиск, фильтры и подборка; `projects.html` — проектная концепция до передачи реального портфолио; `about.html`; `contacts.html`; `privacy.html`.

## Ограничения

- Формы заявок пока демо: пользователь может скопировать/скачать текст, автоматической передачи в студию нет.
- Часы работы и ссылки на именно карточки организации в 2ГИС ещё не подтверждены; ссылки маршрута открывают поиск по адресу.
- Магазин — подборка классов/типов плёнок, без выдуманных товаров, цен, складских остатков и брендов.
- Реальные отзывы и фото работ отсутствуют; не выдавать иллюстрации за выполненные проекты.
- До подключения юридически корректной обработки заявок сохранены `noindex` и `robots.txt: Disallow`.
- Доступность: клавиатурный фокус, мобильное меню, поддержка prefers-reduced-motion.
