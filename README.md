Новый проект, написанный с чистого листа. Ветка опубликована через GitHub Pages в корне репозитория `and77777-png/24-38-website`.

## Структура
- `index.html` — главная в духе автомобильного премиум-сайта: полноэкранный Corvette, услуги, проекты, магазин, о студии, контакты.
- `services.html` — 14 направлений услуг; первым пунктом добавлена оклейка бронеплёнкой (PPF), прежние 13 сохранены.
- `shop.html` — 12 типов плёнок, категории, поиск, цена по запросу.
- `projects.html` — макет галереи без вымышленных выполненных работ.
- `video.html` — подготовленный раздел видео с честными заглушками.
- `contacts.html` — два филиала с маршрутами, телефонами и адаптивной встроенной картой OpenStreetMap (выбор филиала).
- `privacy.html` — объяснение обработки данных в демонстрационном режиме.

## Проверка карты
Вместо Leaflet (разлетавшаяся плиточная карта при недоступности внешней CSS) применено iframe OpenStreetMap внутри контейнера фиксированной высоты с переключателем филиалов. Номера и маршруты 2ГИС доступны независимо от загрузки карты. Положение строения на Высотной ориентировочное.

Локально проверена геометрия аналогичной карты в Chromium на ширинах 320, 360, 375, 390, 430, 600, 760, 768, 900, 1024, 1280 и 1440 px: горизонтального переполнения нет. Внешнюю загрузку тайлов внутри встроенной карты проверить из офлайн-среды нельзя.
