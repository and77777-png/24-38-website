# 24-38 — демонстрационный сайт

Шесть полноценных страниц плюс политика: `index.html`, `services.html`, `shop.html`, `projects.html`, `about.html`, `contacts.html`, `privacy.html`. Все файлы статические. Откройте `index.html` или разверните содержимое папки в корне отдельного публичного GitHub-репозитория и включите Pages через Settings → Pages → Deploy from a branch → main / root.

- Тёмный премиальный интерфейс, адаптивная мобильная навигация. Визуальный стиль обновлён до V2: живой световой перелив по утверждённому силуэту, объёмная металлизированная типографика, номерной список услуг 1–13, деликатные световые эффекты. Анимации автоматически отключаются при системной настройке уменьшения движения.
- 13 услуг из исходного перечня, с редакторской корректировкой очевидных орфографических неточностей.
- Магазин-каталог с 12 категориями/вариантами плёнок, поиском, фильтрами, локальной подборкой, без выдуманных SKU, брендов, запасов и цен.
- Форма демонстрационная: данные **не передаются** в студию, возможно скопировать или скачать текст заявки.
- Нет искусственных отзывов, портфолио, адресов и телефонов.
- Юридические данные ИП: Цветков Павел Викторович, ИНН 380125100560, ОГРНИП 325385000066263. Источник: https://www.tbank.ru/business/contractor/ogrn-date/2025-06-18/26/. Актуальность следует проверить по выписке ФНС до запуска.
- Включён `noindex` и `robots.txt: Disallow` до завершения согласования.

## Для публичного запуска необходимо

1. Подтвердить название и две карточки филиалов в 2ГИС: адрес, телефон, часы работы, ссылки на карточки. Поиск не смог доказательно сопоставить компанию «24-38» с нужными двумя филиалами.
2. Утвердить ассортимент: бренды, модели, фотографии, характеристики, наличие, единицы измерения и наличие фактических услуг.
3. Предоставить реальные фотографии работ/студии и разрешение на публикацию.
4. Выбрать канал заявок (Telegram/MAX/CRM/e-mail), затем реализовать серверную отправку, антиспам, уведомления и получение согласия.
5. Подготовить юридическую политику и согласие в соответствии с фактической обработкой данных; убрать уведомление `Preview`.
6. Купить/подключить домен, включить HTTPS, актуальные контактные данные, нормальную аналитику, sitemap и индексирование.
7. Файл `assets/sign-reference.jpg` — уменьшенная копия предоставленной пользователем вывески, `assets/car-outline.png` получен из того же изображения.

## GitHub Pages

Создайте новый **публичный** репозиторий `24-38-website`, затем загрузите содержимое этого архива (файлы `index.html`, `services.html`, `shop.html` и папку `assets/` — в **корень** репозитория). Перейдите `Settings → Pages → Build and deployment → Deploy from a branch → main / (root)`. В течение нескольких минут GitHub выдаст адрес вида `https://USER.github.io/24-38-website/`. Это пример формата адреса, не опубликованная ссылка. В preview включён noindex, до утверждения контактов отключать его не следует.
