Новый проект, написанный с чистого листа. Ветка опубликована через GitHub Pages в корне репозитория `and77777-png/24-38-website`.

## Структура
- `index.html` — главная в духе автомобильного премиум-сайта: затемнённый зацикленный видеоролик, услуги, проекты, магазин, о студии, контакты.

- `shop.html` — 12 типов плёнок, категории, поиск, цена по запросу.
- `projects.html` — макет галереи без вымышленных выполненных работ.
- `video.html` — подготовленный раздел видео с честными заглушками.
- `contacts.html` — два филиала с маршрутами, телефонами и адаптивной встроенной картой OpenStreetMap (выбор филиала).
- `privacy.html` — объяснение обработки данных в демонстрационном режиме.

## Проверка карты
Вместо Leaflet (разлетавшаяся плиточная карта при недоступности внешней CSS) применено iframe OpenStreetMap внутри контейнера фиксированной высоты с переключателем филиалов. Номера и маршруты 2ГИС доступны независимо от загрузки карты. Положение строения на Высотной ориентировочное.

Локально проверена геометрия аналогичной карты в Chromium на ширинах 320, 360, 375, 390, 430, 600, 760, 768, 900, 1024, 1280 и 1440 px: горизонтального переполнения нет. Внешнюю загрузку тайлов внутри встроенной карты проверить из офлайн-среды нельзя.

## Фоновое видео
Видео работает с `autoplay muted loop playsinline`, затемняется CSS и масштабируется для десктопа/мобильного экрана. В `assets/hero-video.js` реализованы остановка при скрытой вкладке, недоступной видимости, настройке `prefers-reduced-motion` и режиме экономии данных. При блокировке автозапуска остаётся постер. Подложка содержит текст «Work time.», который встроен в исходное видео; на десктопе позиция кадра выбрана так, чтобы он не перекрывал заголовок.

## Фоновое видео: исправление V2
- Снижено затемнение на компьютере и телефоне, повышена яркость самого ролика; контраст надписей сохранён градиентом со стороны текста.
- Добавлена видимая управляющая кнопка «Смотреть видео / Пауза видео» вне декоративного видеослоя.
- Автозапуск по-прежнему бесшумный (`muted`, `playsinline`, `loop`), ручной запуск возможен на iPhone при ограничениях энергосбережения, Reduce Motion и автозапуска.
- При блокировке видео остаётся постер; CSS не делает видео невидимым до старта и не скрывает его навсегда при Reduce Motion.
- Проверены синтаксис JS, HTML-кнопка, CSS-правила и имена файлов; фактический запуск на физических iOS-устройствах требует внешней проверки.
