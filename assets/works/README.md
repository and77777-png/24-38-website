# Фотографии работ 24/38

Девять исходных фотографий предоставлены владельцем для портфолио. Готовые WebP + миниатюры подготовлены отдельно в архиве `24_38_photo_portfolio_package.zip`. **В этой ветке фотофайлы ещё не загружены**, поэтому не объединять с `main` до переноса всех `.webp` из архива. Категории и подписи — `manifest.json`.

Главная: 3 кадра (зеркало, передняя часть автомобиля, эмблема). Проекты: все 9 фото, фильтры «Бронеплёнка», «Детали и стайлинг», «Оптика». Не выдавать отдельные фотографии одного процесса за девять завершённых заказов.

Пользовательские скриншоты фотографий №2 и №5 подготовлены без интерфейса Telegram; фактические детали на снимках не изменены.
